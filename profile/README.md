# Mailfully

Mailfully is a transactional email API for developers. Your app sends receipts, password resets and sign-in links with one API call, and can receive email by webhook. 5,000 emails a month are free, and paid plans start at $19.

- Website: https://mailfully.com
- Docs: https://mailfully.com/docs
- Pricing: https://mailfully.com/pricing
- Node.js SDK and CLI: https://www.npmjs.com/package/mailfully
- Contact: https://mailfully.com/contact
